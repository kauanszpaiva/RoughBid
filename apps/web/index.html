ROUGH / 03 PROJECT SEQUENCE

One project. Five checkpoints.

RoughBid is organized around the decisions an estimator actually needs to make before a number is ready to send.

  1. 01
    PLANS

    Load the current drawing set.

    Keep the source documents and revisions with the project.

  2. 02
    QUANTITIES

    Review what counts.

    Confirm, edit or dismiss findings before they enter the estimate.

  3. 03
    ESTIMATE

    Build the price.

    Add actual unit costs and understand the effect of overhead and markup.

  4. 04
    REVIEW

    Catch incomplete work.

    Check readiness before anything is released to the client.

  5. 05
    PROPOSAL

    Send the right version.

    Export the client-safe proposal while retaining the internal estimate.
